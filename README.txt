TEMPLATE UNDANGAN PREMIUM

1. Buka index.html di browser.
2. Edit nama, tanggal, alamat, rekening, dan nomor WhatsApp di index.html.
3. Tambahkan musik MP3 dengan nama musik.mp3 ke folder ini.
4. Ganti URL gambar dengan foto sendiri bila diperlukan.
5. Upload seluruh isi folder ke hosting jika ingin dibagikan sebagai website.

Nomor WhatsApp RSVP ada di JavaScript:
let phone='6281234567890';

Tanggal countdown:
const target=new Date("December 12, 2026 08:00:00").getTime();
